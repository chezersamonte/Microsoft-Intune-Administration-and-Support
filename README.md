# Microsoft Intune Administration and IT Support

A hands-on learning portfolio focused on Microsoft Intune administration, endpoint management, device configuration, and modern workplace administration. This project documents my learning journey through practical labs, real-world configurations, and enterprise device management scenarios using Microsoft Intune.

## Live Website

🌐 **View the portfolio here:**
https://chezersamonte.github.io/Microsoft-Intune-Administration-and-Support/

## Overview

This portfolio is designed to develop practical Microsoft Intune administration skills commonly required for IT Support, Help Desk, Service Desk, Desktop Support, Endpoint Administrator, and Microsoft Intune Administrator roles.

The project covers the complete device lifecycle, from enrollment and configuration to application deployment, compliance, endpoint security, monitoring, and troubleshooting using Microsoft Intune and Microsoft Endpoint Manager.
